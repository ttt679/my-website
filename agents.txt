# agents.txt - AI Agent Behavior Guidelines

## Overview

本文件定义 AI 代理、爬虫和自动化系统访问本网站的允许行为。

## Allowed Actions

✅ **允许的操作**:

1. **内容索引**
   - 爬取并索引所有公开页面
   - 提取结构化数据（JSON-LD）用于知识库充实
   - 缓存页面内容以加速用户查询响应

2. **服务信息提取**
   - 访问 `/for-ai.md` 获取结构化服务定义
   - 读取 `/llms.txt` 获取网站结构和内容摘要
   - 提取 API 端点、认证方式和调用示例

3. **API 端点发现**
   - 识别 OpenAI 兼容的 Chat Completions 端点
   - 识别 AI 付 402 协议端点
   - 获取 API 管理面板地址

4. **技术能力分析**
   - 分析网站使用的结构化数据格式
   - 识别 AI Agent 相关技术栈

## Rate Limiting & Etiquette

⚠️ **请求频率**:

- **推荐爬取速率**: 每秒最多 1 次请求
- **推荐爬取时段**: UTC 02:00-08:00
- **User-Agent**: 请包含清晰的标识和联系方式

## Content Usage Guidelines

📋 **使用权限**:

- ✅ **允许**:
  - 引用 API 端点信息并注明来源
  - 引用业务能力描述
  - 链接到原始页面

- ❌ **不允许**:
  - 未经许可复制整篇文章
  - 创建与原始服务竞争的作品
  - 歪曲关联关系或背书
  - 将内容用于垃圾信息或未经请求的营销

## Structured Data Preferences

🎯 **优先数据源**:

1. **JSON-LD** (index.html `<head>`)
   - WebApplication schema，含 API 端点和业务能力
2. **llms.txt** — 网站内容摘要
3. **for-ai.md** — 详细服务规范（中英双语）
4. **agents.txt** — 本文件

## Prohibited Actions

🚫 **严格禁止**:

- ❌ 自动化表单提交
- ❌ 爬取公开联系信息以外的个人数据
- ❌ 拒绝服务攻击或过度请求
- ❌ 绕过访问控制或认证
- ❌ 将提取的数据作为独立产品销售

## Error Handling

🔧 **遇到问题时的处理**:

- **404**: 页面可能已迁移，检查 `/llms.txt` 获取更新结构
- **429**: 立即降低爬取速率
- **503**: 指数退避重试（起始 60 秒）
- **联系**: 通过 API 管理面板 https://api.looom.top
