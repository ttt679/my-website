AI 工作流 自动化 内容分发 决策辅助 AI 付 402 协议

API 端点

# 向 AI 付端点发送请求
curl -X POST https://api.looom.top/api/agent/market/aipaysever \
  -H "Content-Type: application/json" \
  -d '{
    "model": "AI付",
    "messages": [
      {"role": "user", "content": "帮我分析一下最近的销售数据趋势"}
    ],
    "stream": false
  }'
首次请求（无支付凭证）→ 返回 402
HTTP 402 Payment Required Payment-Needed: eyJwcm90b2NvbCI6eyJvdXRfdHJhZGVfbm8iOi... {"error":"Payment Needed","out_trade_no":"ORDER_...","amount":0.05}

AI 付 支付后获取回复

# 支付完成后，携带 Payment-Proof 凭证重试
curl -X POST https://api.looom.top/api/agent/market/aipaysever \
  -H "Content-Type: application/json" \
  -H "Payment-Proof: <base64 支付凭证>" \
  -d '{
    "model": "AI付",
    "messages": [
      {"role": "user", "content": "帮我分析一下最近的销售数据趋势"}
    ],
    "stream": false
  }'
支付流程
  1. 请求端点 → 收到 402 + Payment-Needed 响应头
  2. 通过 alipay-bot / PayGuard 扫码支付
  3. 获取 Payment-Proof 凭证后重试请求
  4. 支付验证通过 → 返回 AI 回复
