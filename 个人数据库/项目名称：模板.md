## 6. 数据本地化与隐私说明（自检清单）
- [ ] API Key 仅存于 .env，已加入 .gitignore
- [ ] 笔记文件仅存于本地磁盘，未自动上传
- [ ] 调用API时发送的内容？[仅当前对话 / 含历史]
- [ ] 是否记录日志？日志是否含敏感信息？
- [ ] 剪贴板内容是否临时落盘？
- [ ] 是否使用第三方服务（如pastebin）？无
- [ ] 若用本地模型，临时文件是否清理？

**需要注意的隐私安全点：**

| 检查项               | 可能风险                                                         | 建议                                                                       |
| ----------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------ |
| **API 调用日志**      | 如果你的代码中有 `print(response)` 或写日志文件，可能会把对话内容或 API Key 打印/保存下来。 | 确保日志只记录时间、状态码，不记录请求体和响应体。或者完全关闭日志。                                       |
| **剪贴板内容临时文件**     | 某些实现会把剪贴板内容先写到临时文件（如 `/tmp/clipboard.txt`），如果忘记删除，其他程序可能读取。  | 优先使用内存操作（如 `pyperclip.paste()` 直接得到字符串），不写临时文件。如果必须写，用完立刻 `os.remove()`。 |
| **API 请求的传输加密**   | 调用外部 API 时，内容会经过网络。                                          | 确保使用 HTTPS 端点；不要在公网未加密传输。                                                |
| **本地模型的临时数据**     | 如果你以后用 Ollama 等本地模型，模型可能会缓存输入输出。                             | 阅读本地模型的隐私说明，定期清理缓存目录。                                                    |
| **系统级剪贴板历史**      | macOS 或 Windows 的剪贴板管理器可能会保存所有复制过的内容。                        | 告知用户（你自己）注意这一点，或者在使用后主动清空剪贴板（例如用 `pyperclip.copy("")`）。                  |
| **前端 Web 页面的输入框** | 如果你通过 localhost 页面输入对话内容，浏览器可能会保存表单历史。                       | 在 HTML 的 input 标签上添加 `autocomplete="off"`。                               |
