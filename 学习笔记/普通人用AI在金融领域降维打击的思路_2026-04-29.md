# 普通人用AI在金融领域降维打击的思路沉淀

## 一、核心认知：重新定义“降维打击”

**真正的降维打击不是对市场的打击，而是对传统学习曲线和成长路径的超越。**

- 传统路径：实盘亏损 → 积累经验 → 缓慢成长
- AI路径：零成本研究 → 快速验证 → 知识沉淀 → 认知跃迁

---

## 二、AI爱好者的三大优势

### 1. 工具思维
- 天然把AI当成可调用、可组合的组件（MCP、本地模型、API）
- 传统金融人还在手动Excel或写死代码

### 2. 数据流动性
- 用Obsidian做知识库，让AI同事共享记忆
- “知识即代码”的思路在金融圈很少见

### 3. 低杠杆试错
- 先做工具、后入金
- 很多人直接拿真金白银赌博

## 三、构建个人AI量化研究流水线

### 3.1 核心架构：Obsidian + MCP + AI同事集群

| 组件 | 作用 | 具体实现 |
|------|------|----------|
| Obsidian Vault | 知识库核心 | 存放：因子公式库、回测日志、策略复盘、市场观察、AI对话记录 |
| MCP Server | 协议层 | 让AI能读写Obsidian里的指定文件夹 |
| AI同事（本地） | 分析/决策 | 通过Ollama运行本地LLM，调用MCP读取知识库 |
| AI同事（云端） | 高性能辅助 | 仅在需要强推理时调用DeepSeek API |
| 量化回测引擎 | 执行层 | 聚宽/掘金的本地版或开源框架 |

### 3.2 完整工作流示例

1. 在Obsidian记下灵感：“北向资金连续3日净流入超50亿 → 5日后创业板指上涨概率高”
2. “回测智能体”AI同事通过MCP读取这条笔记
3. AI自动生成回测代码，调用本地Python环境执行回测
4. 回测结果自动写回Obsidian新笔记，附上AI分析结论
5. 每天打开Obsidian，看到所有策略的更新状态

## 五、从零开始的“无痛学习路线”

### 第0周：搭建最小环境
- 安装Python + Jupyter Notebook
- 安装几个库：pandas, numpy, matplotlib, akshare
- 跑通第一行代码：获取一只股票的历史日线数据

### 第1-2周：模仿一个最简单的alpha
- 打开WorldQuant的“101个alpha”文档
- 把公式翻译成Python代码，在历史数据上计算每天的alpha值
- 用AI帮忙写代码

### 第3-4周：做一个最简陋的“回测”
- 假设每天买入alpha值排名前10%的股票
- 持有一天后卖出，计算每天的收益率
- 画出累计收益曲线

## 六、资金与风险管理

### 6.1 资金门槛的现实
- 基础量化权限：10万元（主流券商门槛）
- 专业版：50万至100万元
- 进阶玩家：高频交易需极速柜台（50万至100万）

### 6.2 凯利公式：最优仓位分配
- **简单版**（输赢金额相等）：f = p - q
- **通用版**（不同盈亏比）：f = (p * b - q) / b
- **实用建议**：使用半凯利或四分之一凯利

### 6.3 f为负的含义
- f < 0：策略期望值为负，长期必然亏损
- 最优选择：不参与
- 反向操作机会：如果f为负，可以考虑做反向策略

## 七、从“零资金”到“有本金”的路径

### Step 1：启动（0元）
- 注册聚宽或掘金账号
- 学习免费的量化基础和Python策略开发

### Step 2：研究（0元）
- 聚焦“回测总量”的灵感
- 在免费研究环境里编写因子、编写回测逻辑

### Step 3：积累（0元）
- 将研究成果提交到策略社区讨论
- 积累数据和技术壁垒，打造个人影响力

### Step 4：变现（0元投入）
- 通过策略商城、技术服务等方式创造第一笔非投资性收入

### Step 5：投资（首次投入）
- 攒够几百元时，作为起步本金
- 用一个极小的仓位真正启动投资之旅

## 八、需要警惕的三大陷阱

### 1. 市场微观结构与规则
- 涨跌停、T+1、停牌、退市、大宗交易、龙虎榜规则
- 不掌握这些“脏活”，AI再聪明也会踩坑

### 2. 风险与资金管理
- 一次黑天鹅可能让策略爆仓
- 凯利公式和仓位管理比预测更重要

### 3. 过拟合与未来函数
- 回测漂亮不代表实盘有效
- 金融数据信噪比极低，AI很容易学到噪声
- 需要严谨的样本外验证和滚动窗口测试
