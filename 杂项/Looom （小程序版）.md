## Looom turns information into understanding. We're not waiting for the future—we're building it, thread by thread.
Looom 将信息转化为理解。我们不等待未来——我们在一线一线地编织它。



## 阶段一：前期准备（2-3 天）

### 1. 注册微信小程序账号

- 访问 [微信公众平台](https://mp.weixin.qq.com/)
    
- 选择「小程序」→「立即注册」
    
- 主体类型选择 **个人**
    
- 填写身份证信息、手机号，完成注册
    

### 2. 完成微信认证（必须）

- 登录小程序后台，进入「设置」→「基本设置」→「微信认证」
    
- 支付 **30元/年** 认证费，按提示提交身份证照片、人脸识别
    
- 认证通过后，才能进行备案和发布
    

### 3. 小程序备案

- 认证通过后，在「设置」→「基本设置」→「备案」中提交备案信息
    
- 需准备：身份证照片、人脸识别、小程序名称（Looom）、服务内容标识（工具-信息查询）
    
- 备案周期约 **1-2 周**，期间可以先进行开发
    

### 4. 注册域名（用于后端 API）

- 建议购买一个简洁域名（如 [loomlab.cn](https://loomlab.cn/) 或 looom.app）
    
- 推荐腾讯云/阿里云，首年约 **30-50 元**
    
- 后续需要配置 SSL 证书（免费），用于 HTTPS 访问
    

### 5. 申请联盟账号（返佣）

- **淘宝联盟**：注册账号，获取 `appKey` 和 `secret`
    
- **京东联盟**：注册账号，获取 `appKey` 和 `secret`
    
- 初期可以先接入一家，后续再扩展
    

---

## 阶段二：开发环境搭建（1 天）

### 1. 安装开发者工具

- 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
    

### 2. 创建项目

- 打开开发者工具，用小程序账号扫码登录
    
- 创建项目：项目名称 `Looom`，选择小程序模式，AppID 从后台获取
    
- 后端服务建议选择 **微信云开发**（初期免服务器运维）
    

### 3. 开通云开发（若选择云开发）

- 在开发者工具中点击「云开发」按钮，按指引开通环境
    
- 获得环境 ID，后续云函数将在此运行
    
- 免费版配额足够初期测试（1GB 存储 / 100 万次调用 / 月）
    

### 4. 配置域名白名单（若自建服务器）

- 若自建后端，需在小程序后台「开发」→「开发设置」→「服务器域名」中配置 `request` 合法域名
    
- 必须是 HTTPS，且已备案的域名

## 阶段三：后端开发（2-3 天）

### 核心功能

- 接收用户传入的商品链接
    
- 解析出平台（淘宝/京东/拼多多）和商品 ID
    
- 调用 OpenAI API 提取面料成分、版型等信息
    
- 调用评分引擎计算各场景得分
    
- 调用联盟 API 生成返佣链接
    
- 返回结果给小程序
    

### 使用云开发（推荐）

- 创建云函数 `analyze`，处理上述逻辑
    
- 代码示例（Node.js）：
    

javascript

// 云函数入口
const cloud = require('wx-server-sdk')
cloud.init({ env: 'your-env-id' })
const axios = require('axios') // 需在 package.json 中引入
exports.main = async (event, context) => {
  const { url } = event
  // 1. 解析平台和商品ID（正则或第三方库）
  // 2. 获取页面 HTML 或调用平台 API 获取商品信息（注意反爬，可先用模拟请求）
  // 3. 调用 OpenAI 提取成分、版型等
  // 4. 调用评分引擎（可内嵌规则）
  // 5. 调用联盟 API 生成返佣链接
  // 6. 返回结果
  return {
    score: {...},
    buyLink: '...'
  }
}

- 依赖包：`axios`、`cheerio`（若需解析 HTML）、`openai` 等
    
- 注意云函数超时时间默认 3 秒，可调整为 20 秒（在云函数配置中）
    

### 评分引擎规则（可内置于云函数）

- 根据成分比例和版型关键词，按照之前设计的 5 个维度打分
    
- 实现“软性否决”逻辑：若锦纶 >70% 且非西裤版型 → 商务场景直接低分
    

### 注意事项

- OpenAI API Key 需妥善保管，可放在云函数环境变量中
    
- 联盟 API 调用可能需要签名，按照官方文档实现
    
- 每次调用成本：OpenAI 约 $0.002 左右，初期可免费额度覆盖

## 阶段四：前端开发（3-5 天）

### 页面结构

- **首页**：输入框（粘贴链接）+ 分析按钮
    
- **结果页**：展示商品图片（若有）、标题、各场景得分（卡片形式）、推荐理由、购买按钮
    
- **历史记录**（可选）：保存用户最近查询的商品
    

### 关键功能实现

1. **剪贴板读取**
    

javascript

wx.getClipboardData({
  success: (res) => {
    const link = res.data
    // 自动填充到输入框
  }
})

2. **调用云函数**
    

javascript

wx.cloud.callFunction({
  name: 'analyze',
  data: { url: inputValue },
  success: (res) => {
    // 展示结果
  }
})

3. **跳转购买**
    
    - 由于个人主体无法在小程序内直接跳转淘宝/京东 App，可采用以下方案：
        
    - 复制链接到剪贴板，提示用户「已复制购买链接，请到浏览器打开」
        
    - 或使用 `web-view` 打开一个 H5 页面，在 H5 中再引导跳转（但需配置业务域名）
        
4. **分享功能**
    

javascript

onShareAppMessage() {
  return {
    title: 'Looom - AI帮你选衣服',
    path: '/pages/index/index'
  }
}

### 样式与体验

- 使用微信官方设计指南，保持简洁
    
- 加载时添加 loading 状态
    
- 适配深色模式（可选）

## 阶段五：测试与调试（1-2 天）

1. **真机调试**：用开发者工具的「真机调试」功能，在不同机型上测试
    
2. **功能测试**：
    
    - 测试淘宝、京东、拼多多链接是否能正常解析
        
    - 测试各种面料配比的评分准确性
        
    - 测试返佣链接生成与复制
        
3. **性能测试**：云函数响应时间应在 5 秒以内
    
4. **边界情况**：无效链接、无成分信息、网络超时等，需有友好提示

## 阶段六：提交审核与发布（1-3 天）

### 1. 准备提交材料

- 小程序名称：`Looom`（需未被占用）
    
- 简介：可使用你选定的那句话（15 字以内）
    
- 服务类目：`工具` → `信息查询`
    
- 图标：1024x1024 的 PNG
    
- 截图：至少 4 张功能截图，尺寸符合要求
    

### 2. 提交代码

- 在开发者工具中点击「上传」，填写版本号
    
- 登录小程序后台，进入「版本管理」，选择「提交审核」
    

### 3. 常见审核驳回原因及应对

|驳回原因|解决方案|
|---|---|
|类目不符|确保选择“工具-信息查询”，不要选择“电商平台”|
|功能不完整|确保所有功能都能正常使用，无空白页|
|诱导分享|不要在返佣逻辑中强制要求分享|
|涉及支付无资质|返佣走联盟链接，不在小程序内直接支付|
|隐私政策缺失|在「设置」→「用户隐私保护指引」中完善|

### 4. 审核通过后发布

- 审核通过后，在后台点击「发布」即可上线
    
- 发布后约 1 小时，用户即可在微信中搜索到
